The fastest way to get a site that looks exactly like our demo is to import the demo data. Follow the steps below.

**Step 1:** Install the Simple & Elegant theme. If you’ve already done this, move on to step 2.

**Step 2:** Install all required plugins under **Dashboard > Appearance > Install Plugins**. Otherwise, your portfolio won’t be imported. If you are setting up an eCommerce website, also install the **WooCommerce** plugin — Simple & Elegant works perfectly with it.

**Step 3:** Go to **Dashboard > Appearance > Import Demo Data** and select the demo you want to import. Wait 5–15 minutes (our server and images are located in the USA). You can verify the import is working by opening a new tab and going to **Dashboard > Media** to see new images being added to your site. A notice appears when the import has completed.

![Appearance > Import Demo Data screen showing the Main Demo with an Import Demo Data button](/simple-elegant/assets/se-import-demo-data.png)

### Backup method: import manually

It’s rare, but possible: if your server isn’t strong enough, or there are issues during the one-click import, use the manual method below.

**Step 3b:** Go to **Dashboard > Tools > Import** and click the **WordPress** link (the last option) to install the WordPress Importer.

![Tools > Import screen with the WordPress importer Run Importer link highlighted](/simple-elegant/assets/se-tools-import-wordpress.png)

**Step 4b:** Click **Run Importer** and upload the `demo.xml` file from your theme package. There are 3 demos and 3 XML files, located in `/simple-elegant/inc/demos/`. Click **Upload and run importer**, and be sure to check **“Download and import file attachments”**. The import takes about 2–15 minutes depending on your server connection.

![WordPress Importer Assign Authors and Import Attachments options](/simple-elegant/assets/se-importer-assign-authors.jpg)

**Step 5b:** Go to **Dashboard > Settings > Reading** and set your homepage to **Home** and your blog page to **Blog**.

![Settings > Reading screen with a static page set as the front page](/simple-elegant/assets/se-settings-reading-frontpage.png)

**Step 6b:** Go to **Dashboard > Appearance > Menus** to set up menu locations. Assign menus to the right positions:

- **Primary** → Primary Menu
- **Topbar** → Topbar

![Menus screen Menu Settings with Primary Menu display location selected](/simple-elegant/assets/se-menu-display-location.png)

### Import the sliders

**Step 7:** Go to **Dashboard > Slider Revolution** and click **Import Slider**. Import the sample slider(s) from your download package. Each demo has its own slider(s) that need to be imported:

- **Main Demo:** `main-slider.zip`, `main-small-slider.zip`, `main-shop-slider.zip`
- **Photography Demo:** `photography.zip`
- **DIY Demo:** `diy.zip`

![Slider Revolution Import Slider option](/simple-elegant/assets/se-import-slider.jpg)

**Step 8:** Go to **Dashboard > Appearance > Widgets** to set up your footer widgets, and **Dashboard > Appearance > Customize** to customize your site’s look.
